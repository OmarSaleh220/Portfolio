# نظام حسابات الشركة — Source Code

مشروع كامل: باك اند (Node.js بدون أي مكتبات خارجية) + واجهة أمامية (React عبر CDN).
البيانات بتتخزّن في **قاعدة بيانات SQL حقيقية (SQLite)** على السيرفر — عن طريق موديول `node:sqlite` المدمج في Node.js نفسه (بدون أي تثبيت مكتبات)، فبقت الحسابات متاحة من أي جهاز يفتح رابط السيرفر — مش محبوسة في متصفح واحد زي localStorage.

## المديولات المتاحة حاليًا
- المحاسبة والمالية: شجرة حسابات، معاملات مالية (قيود يومية) ببيان لكل بند وقابلة للتعديل، بالجنيه أو بالدولار مع سعر الصرف، فواتير بيع/شراء بأصناف متعددة وطباعة (مع خانة توقيع للمدير المسؤول والمحاسب)، قوائم مالية (دخل، مركز مالي، ميزان مراجعة، كشف حساب لكل حساب، دفتر يومية) كلها قابلة للطباعة
- لوجو تلقائي للشركة (شعار SVG بمبدأ الحروف الأولى) يظهر في الشريط الجانبي، شاشات الدخول، والفواتير والتقارير المطبوعة
- العملاء والموردون والبنوك
- المخزون: منتجات بباركود/كود، أسعار تكلفة وبيع، كمية حالية محسوبة تلقائيًا من الفواتير، تنبيه كمية منخفضة
- الموارد البشرية: بيانات الموظفين (القسم، المدير المباشر)، هيكل تنظيمي (عرض قائمة/شجري)، الحضور والانصراف، تشغيل رواتب شهرية وترحيلها كقيد محاسبي فعلي (مدين رواتب / دائن بنك)
- المستخدمون: تسجيل دخول بيوزر نيم/باسورد — **المسؤول فقط هو اللي يقدر يضيف مستخدمين جدد** (مفيش تسجيل ذاتي)، وهو كمان اللي يقدر يعدّل بيانات الشركة والأرصدة الافتتاحية ويرحّل الرواتب
- لوحة تحكم: إجماليات، رسم بياني شهري، أكثر العملاء تعاملاً، تنبيه المخزون المنخفض
- عربي / إنجليزي (زرار تبديل اللغة)

## مش موجود لسه (يحتاج مرحلة تانية لو عايزها)
- نقطة بيع (POS) منفصلة عن الفواتير
- لوحات BI متقدمة بتحليلات ورسوم بيانية متعددة قابلة للتخصيص
- صلاحيات دقيقة على مستوى كل شاشة/عملية (RBAC كامل) — حاليًا فيه مستوى بسيط (مسؤول/مستخدم)

## طريقة التشغيل على جهازك

1. ثبّت **Node.js الإصدار 22.5.0 أو أحدث** (من nodejs.org — لازم إصدار حديث عشان قاعدة بيانات SQL المدمجة `node:sqlite`؛ لو عندك إصدار أقدم لازم تحدّثه).
2. افتح Terminal / Command Prompt في مجلد المشروع.
3. شغّل:
   ```
   node server.js
   ```
   أو:
   ```
   npm start
   ```
4. هيظهرلك:
   ```
   نظام الحسابات شغّال على: http://localhost:3000
   قاعدة بيانات SQL: .../data.db
   ```
   (ممكن يظهر تحذير `ExperimentalWarning: SQLite is an experimental feature` — ده طبيعي وليس خطأ، جزء من الميزة دي في Node.js.)
5. افتح المتصفح على `http://localhost:3000` وابدأ.

**ترحيل تلقائي:** لو كان عندك نسخة سابقة من النظام بتستخدم ملف `data.json`، السيرفر هيكتشفه أول ما يشتغل وينقل كل بياناتك تلقائيًا لقاعدة الـ SQL الجديدة، ويسمي الملف القديم `data.json.migrated` كنسخة احتياطية.

**ملاحظة:** المشروع مفيهوش أي `npm install` مطلوب — الباك اند وقاعدة البيانات مكتوبين بمكتبات Node الأساسية بس. الواجهة الأمامية بتحمّل React و Tailwind من الإنترنت (CDN)، فمحتاج اتصال إنترنت وقت الاستخدام حتى لو السيرفر شغّال محليًا.

## إزاي تشغّله على أكتر من جهاز / لموظفينك

دلوقتي البيانات مش متخزنة في متصفح — هي متخزنة في السيرفر نفسه. يعني لو شغّلت السيرفر على جهاز واحد في المكتب (مثلاً جهازك أو سيرفر صغير)، أي حد على نفس الشبكة يقدر يفتح:
```
http://<الـ IP بتاع الجهاز اللي شغّال عليه السيرفر>:3000
```
ويشتغل على نفس البيانات.

## لو عايزه شغّال على الإنترنت (يفتح من أي مكان، مش بس نفس الشبكة)

محتاج تستضيف السيرفر على خدمة استضافة. أسهل خيارات لمشروع زي ده:
- **Render** أو **Railway** — تريد المشروع، تربطه بحساب GitHub، ويشغّل `node server.js` تلقائيًا (فيها خطة مجانية محدودة).
- **VPS** بسيط (زي DigitalOcean أو Hetzner) — ترفع المشروع وتشغّله بأمر `node server.js` (يفضل تستخدم أداة زي `pm2` عشان يفضل شغّال باستمرار).

قولّي لو عايزني أجهزلك خطوات النشر بالتفصيل لأي خدمة من دول.

## نقطة مهمة عن الأمان

النظام فيه تسجيل دخول بيوزر نيم/باسورد، لكن **كلمات السر مخزّنة كنص عادي في قاعدة البيانات** (زي أغلب الأنظمة الداخلية البسيطة) — مناسب تمامًا للاستخدام الداخلي على شبكة المكتب، لكن لو هتنشره على الإنترنت العام، يفضّل تضيف تشفير لكلمات السر (hashing) وHTTPS قبل ما تحط عليه بيانات حقيقية حساسة. قولّي لو عايزني أضيفهم.

## نسخة احتياطية من بياناتك

كل بيانات الشركة (الحسابات، الفواتير، المعاملات، العملاء...) في قاعدة بيانات SQL واحدة: `data.db` بجانب `server.js`. خد نسخة منه بانتظام (أو حطه في مجلد بيتزامن مع Google Drive / OneDrive) عشان تكون بياناتك محفوظة. تقدر كمان تفتحه بأي أداة SQLite عادية (زي DB Browser for SQLite) لو عايز تستعلم على بياناتك مباشرة.

## الـ API (لو حابب تطوّر عليه)

- `GET /api/data` → يرجع كل بيانات الشركة الحالية (JSON)
- `PUT /api/data` → يستبدل كل البيانات بالي في جسم الطلب (JSON)

الواجهة الأمامية بتستخدم الاثنين دول بس — تحميل البيانات أول ما تفتح الصفحة، وحفظها أول ما تعدّل أي حاجة.
